# WebPS

无需后端的浏览器端轻量图像编辑器，可直接发布到 GitHub Pages。

## 功能

- 多图层、透明度、可见性与常见混合模式
- RGB / R / G / B / Alpha 通道独立显示和绘制
- PNG、JPG、WebP 等常见图片导入，以及 24/32-bit 未压缩或 RLE TGA 导入
- 画笔、橡皮、吸管、魔术棒、油漆桶、可移动像素的矩形选区、内部复制/剪切/粘贴、移动画布
- 亮度、对比度、饱和度；高斯/盒式/动感/径向模糊；锐化、USM、描边和反相
- PNG、JPG、WebP、32-bit TGA 导出
- 本地撤销/重做历史，不上传图像

## 使用与部署

直接用浏览器打开 \`index.html\` 即可使用。部署 GitHub Pages 时，将仓库根目录作为发布目录；不需要构建命令或环境变量。

快捷键：\`B\` 画笔、\`E\` 橡皮、\`I\` 吸管、\`M\` 选区、\`H\` 移动画布、\`Ctrl/Cmd+Z\` 撤销、\`Ctrl/Cmd+Shift+Z\` 重做。

## 边界

项目不读取或写入 PSD。单个画布限制在 8192 × 8192 像素以内。
